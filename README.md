This is a game called Canon & Basketball. Aim of this game is to shoot all the baskets. It contains 7 simple levels.

Controls - 
A & D -> Power control
W & S -> Angle control
Space -> Shoot

This game is inspired by Dude Perfect 2 game, which is no longer available to download.

Created by - RandomHimalayanGuy (that's me)

Extra assets used - Basketball image, sound effects and background music (all Free to use)

Created with Godot  <3
