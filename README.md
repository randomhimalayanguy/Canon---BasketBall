
**Cannon & Basketball, [Play here](https://randomhimalayanguy.itch.io/canon-basketball)**  
A fun, arcade-style game where the goal is to shoot all baskets across 7 engaging levels.

**Controls**  
- **A & D**: Adjust power  
- **W & S**: Set angle  
- **Space**: Shoot  

**Inspiration**  
Inspired by the classic *Dude Perfect 2* game (no longer available).

**Created by**  
RandomHimalayanGuy  

**Assets**  
- Basketball image, sound effects, and background music (all free to use)  

**Built with**  
Godot Engine <3
